# ValuCast Reach Program (Weekly Cadence)

**Adopted:** 2026-07-30 (owner directive). **Cadence: weekly, fixed —
never continuous.** Constant competitor watching creates reactive
decisions; the audit fires Mondays 13:00 UTC and at no other time.

## 1. Weekly public landscape report

Per tracked account: follower growth, median impressions, engagement
rate, posting cadence, successful formats, collaboration activity.
Data sources: owner-supplied platform exports dropped at
`data/manual/reach/` (or the session scratchpad `reach/`), plus
read-only public fetches that violate no platform terms. Metrics without
a connected source are listed as "needs owner export/connector" — never
estimated.

## 2. ValuCast growth scorecard

Impressions per follower · follows per 1,000 impressions · profile
visits · site clicks · returning visitors. Site-side metrics come from
whatever analytics the owner supplies or commits; social-side from
exports. Same no-fabrication rule.

## 3. Consistent programming

Daily signal · two weekly deep dives · one weekly board/movers post ·
immediate call-up receipts. The weekly audit verifies the published
cadence against repo evidence (data commits, artifacts, share routes).

## 4. Selective collaboration — hard boundary

Interact with credible creators and exchange public analysis. **Never
pool ValuCast's scoring or proprietary data.** This is the social
extension of the standing technical boundary (PROHIBITED_SCORE_INPUTS,
observe-only source policies): external parties can receive ValuCast
outputs; nothing external enters the model, and no partner sees
non-public internals.

## 5. Independent ValuCast network

Build direct relationships — dynasty commissioners, team-specific
writers, podcasts, prospect accounts — who receive useful graphics or
analysis with no influence over the model. The competitors' advantage is
coordinated distribution; ValuCast replicates the distribution benefit
without surrendering independence, the trait that can make it the
trusted standard.
